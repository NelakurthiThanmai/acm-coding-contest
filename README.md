
# ACM Coding Contest

## About the Project

This project is a prototype for an ACM coding contest. The main idea is to make the coding contest more interesting by dividing it into different levels.

Participants start from Level 1 and move to the next level based on their performance.

## Contest Levels

### Level 1 - Basic

This level contains simple programming questions.

Topics include:

* Basic logic
* Loops
* Conditions
* Strings
* Simple arrays

The main purpose of this level is to check the basic coding knowledge of participants.

### Level 2 - Intermediate

Level 2 has more difficult questions compared to Level 1.

It includes:

* Arrays
* Strings
* Searching
* Sorting
* Mathematical problems
* Logical problems

Participants have to complete Level 2 to qualify for the next level.

### Level 2 Qualifier

After Level 2, the participant's performance is checked.

Only the participants who qualify can move to Level 3.

Level 3 will remain locked until it is opened for the qualified participants.

### Level 3 - Advanced

This is the final and most difficult level.

It contains challenging programming problems, especially difficult array and algorithm problems.

This level is mainly used to test the participant's problem-solving and coding ability.

## Contest Time

Total contest time: **1 hour 40 minutes**

The time is divided between the three levels so that the difficulty increases step by step.

## Main Features

* Gaming-style interface
* Login page
* 3 levels
* Level-wise difficulty
* Timer
* Level 2 qualification
* Locked Level 3
* Score calculation
* Interactive questions
